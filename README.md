# Contenido_Colabs_SIC

Repositorio que contiene el material práctico y los archivos **Google Colab** utilizados y desarrollados durante las clases del programa **SIC**.

Este repositorio funcionará como un punto central de consulta para acceder al contenido trabajado durante las clases, incluyendo notebooks, ejemplos, ejercicios, prácticas y material complementario.

El contenido se irá **actualizando semanalmente** conforme avancemos en los diferentes bloques del programa.

---

## 🎯 Objetivos

Este repositorio tiene como objetivos:

- Centralizar el contenido práctico desarrollado durante las clases.
- Facilitar el acceso a los archivos y notebooks de **Google Colab**.
- Permitir consultar y repasar fácilmente el material de semanas anteriores.
- Proporcionar ejemplos y ejercicios para continuar practicando fuera de clase.
- Mantener organizado el contenido según los diferentes bloques del programa.
- Servir como material de apoyo y referencia durante el desarrollo del curso.

---

## Estructura del repositorio

El contenido estará organizado en diferentes directorios según el bloque del programa al que corresponda.

### 🐍 `Python_colabs`

Contiene los archivos **Google Colab** correspondientes al bloque de **Python**.

En este directorio se almacenará todo el contenido desarrollado durante las clases relacionadas con Python, incluyendo conceptos fundamentales, ejemplos prácticos, ejercicios, prácticas, implementaciones y material complementario.

### 🤖 `IA_colabs`

Contiene los archivos **Google Colab** correspondientes al bloque de **Inteligencia Artificial (IA)**.

Aquí se encontrará el material utilizado para desarrollar los conceptos, herramientas y prácticas relacionadas con Inteligencia Artificial.

### ✨ `IA_Gen_colabs`

Contiene los archivos **Google Colab** correspondientes al bloque de **Inteligencia Artificial Generativa (IA Generativa)**.

En este directorio se incorporará contenido relacionado con modelos generativos, herramientas de IA generativa, experimentación con modelos, ejemplos prácticos, ejercicios y aplicaciones de IA generativa.

### 🗓️ `Sabatinos_colabs`

Contiene el material desarrollado durante las **tutorías sabatinas**, así como contenido adicional o complementario al programa regular.

Este directorio puede incluir:

- Ejercicios adicionales.
- Repasos.
- Prácticas.
- Material de refuerzo.
- Experimentos.
- Contenido complementario.
- Temas adicionales desarrollados durante las tutorías.

## 📝 Nomenclatura del contenido

Para mantener una estructura consistente y facilitar la búsqueda de los diferentes materiales, los archivos y directorios seguirán una nomenclatura estándar.

El formato general será:

```text
XXXX_SemanaXX_CapX/X_tema
```

### Significado de cada elemento

| Elemento | Descripción |
|----------|-------------|
| `XXXX` | Nombre o abreviatura del bloque de contenido |
| `SemanaXX` | Número de la semana en la que se desarrolla el contenido |
| `CapX/X` | Número del capítulo y parte correspondiente |
| `tema` | Tema específico desarrollado en el contenido |

### Ejemplos

```text
Python_Semana01_Cap1/2_tema
IA_Semana10_Cap2/2_tema
IA_Gen_Semana15_Cap1/2_tema
```

Por ejemplo:

```text
Python_Semana03_Cap2/1_Listas
```

Este nombre indica que el contenido corresponde a:

- **Bloque:** Python
- **Semana:** 03
- **Capítulo:** 2
- **Parte:** 1
- **Tema:** Listas

De esta manera, el nombre permite identificar rápidamente qué contenido es, a qué bloque pertenece y en qué momento del programa fue desarrollado.

## ¿Cómo utilizar este repositorio?

Para aprovechar mejor el contenido:

1. **Identifica el bloque** que deseas consultar.
2. Ingresa al directorio correspondiente:
   - `Python_colabs`
   - `IA_colabs`
   - `IA_Gen_colabs`
   - `Sabatinos_colabs`
3. Utiliza la **nomenclatura de los archivos** para identificar la semana, capítulo y tema.
4. Abre el notebook correspondiente y ejecútalo en **Google Colab**.
5. Utiliza los ejemplos y ejercicios como material de práctica y repaso.
